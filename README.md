# Sales Performance Bike & Customer Behavior Analysis Using SQL

___
This project aims to analyze sales performance, products, and customer behavior using SQL, enabling the company to make data-driven decisions to increase revenue and profit.
The dataset used contains sales information such as date, customer age, gender, location, product category, order quantity, price, cost, profit, and revenue.

___
🎯 Business Problem
This project aims to answer the following questions:
1. Which product categories generate the highest profits?
2. Which products generate revenue with low profit margins?
3. Which age groups and age categories are most profitable?
4. Monthly and annual sales trends: are there any patterns?
5. Which countries contribute the highest profits?

📊 SQL Analysis
SQL is used to:
- Calculate total revenue, profit, and margin percentage per product category
- Find top products with high revenue but low profit margins
- Analyze customer segmentation by age and age category
- View monthly and annual sales trends
- Determine top states and countries based on revenue and profit

🔧 Tools & Skills
- SQL: SELECT, JOIN, CTE, Window Function, Aggregate, CASE, ROUND
- Data Cleaning & Transformation
- Data Visualization: Power BI
- Data Storytelling & Business Insights

Takeaways

- Transform raw data into actionable business insights
- Segment customers and products for marketing and pricing strategies
